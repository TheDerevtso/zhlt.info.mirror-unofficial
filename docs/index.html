Zoner's Half-Life Tools (ZHLT / VHLT)

This is the official documentation reference for Zoner's Half-Life Tools (ZHLT).

Zoner's Half-Life compile tools offer many improvements over the original map compiling tools for Half-Life, such as better lighting quality, faster vis times, switchable texture based lighting, support for brush entities casting shadows, removal of "sticky" edges, support for 64-bit processors, and much more. The most recent version of ZHLT is called VHLT (short "Vluzacn's Zoner's Half-Life Tools") and is maintained by Vluzacn
