## What is ZHLT?
**ZHLT** (*Zoners Half-Life Tools*) is a collection of [compiler-compiler](http://en.wikipedia.org/wiki/Compiler-compiler) tools for [Half-Life](http://en.wikipedia.org/wiki/Half-Life) and games or mods running on the [GoldSrc](http://en.wikipedia.org/wiki/GoldSrc) [graphics engine](http://en.wikipedia.org/wiki/Game_engine). The suite is based on the "q" tools, which came with the original GoldSrc [software development kit](http://en.wikipedia.org/wiki/Software_development_kit).

They are the de-facto standard in HL1 engine mapping, and have probably been used for 85%+ of all maps released for HL1, Counter-Strike, TFC, and so forth. On any mapping forum, beginners are immediately advised to forget the default tools and get ZHLT. They are a "[household name](http://en.wikipedia.org/w/index.php?title=Household_name&action=edit&redlink=1)" among half-life mappers. 

Zoner's Half-Life compile tools (ZHLT) offer many improvements over the original map compiling tools for Half-Life, such as better lighting quality, faster vis times, switchable texture based lighting, support for brush entities casting shadows, removal of "sticky" edges, support for 64-bit processors, and much more. 

ZHLT 3.4 (final) was released on 24th February 2006. Its official sequel, developed by Vluzacn, is known as [VHLT](https://developer.valvesoftware.com/wiki/VHLT).
